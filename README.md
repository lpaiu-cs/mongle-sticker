# 몽글몽글 바탕화면 메모 스티커 (Desktop Memo Sticker) 🌸

몽글몽글하고 부드러운 파스텔 톤 디자인의 윈도우(Windows)용 바탕화면 메모 스티커 프로그램입니다.
가볍게 동작하며, 바탕화면의 일부처럼 뒤에 깔끔하게 녹아드는 위젯 형태로 만들어졌습니다.

## 🌟 주요 기능
- **다중 스티커 지원**: 여러 개의 텍스트(`.txt`) 파일을 각각의 스티커로 바탕화면에 띄울 수 있습니다.
- **실시간 동기화**: 원본 텍스트 파일을 수정하고 저장하면 스티커 내용도 즉시 갱신됩니다.
- **개별 상세 꾸미기**: 스티커마다 투명도 조절, 파스텔톤 배경 색상 변경, 원본 텍스트에서 표시할 특정 줄(Line) 범위 지정을 개별적으로 설정 가능합니다.
- **바탕화면 고정 최적화**: 일반 프로그램들보다 항상 뒤에 깔리고, 마우스 클릭이 뚫리거나 다른 아이콘 사용에 방해를 주지 않는 형태로 작동합니다.
- **편리한 UI 설정**: 시스템 트레이 아이콘을 통해 스티커 위치 및 크기를 직관적으로 드래그 조절할 수 있는 설정 창을 제공합니다.

## 🛠️ 기술 스택
- **Python 3.11**
- **PyQt6** (GUI 윈도우 렌더링, 시스템 트레이 제어, 파일 변경 감지)
- **PyInstaller** (실행 파일 패키징)

## 🚀 사용 가이드
1. 스티커 앱을 실행하면 우측 하단 트레이 아이콘(구름/핑크 톤 아이콘)이 나타납니다.
2. 트레이 아이콘을 우클릭하여 **'⚙️ 스티커 관리 / 크기 조절'**을 클릭해 설정 창을 엽니다.
3. 설정 창에서 **`➕ 새 스티커 바탕화면에 추가`** 버튼을 누른 뒤, 연결할 `.txt` 파일을 선택합니다.
4. 바탕화면에 스티커가 나타나면(점선 테두리 모드), 마우스로 드래그하여 원하는 위치에 놓거나 우측 하단을 잡아 크기를 조절합니다.
5. 설정 창 내의 각 스티커 행에서 **`⚙️ 상세`** 버튼을 눌러 스티커 색상과 투명도를 내 취향에 맞게 바꾸고, 미리보기를 보며 표시할 줄(예: `1-5`)을 설정합니다.
6. 설정이 다 끝났다면 **`✅ 설정 완료`** 버튼을 눌러 스티커를 고정합니다!

## 📦 설치 및 빌드 방법 (소스 코드로 실행할 경우)

이 프로젝트의 소스 코드를 직접 실행하거나 패키징하려면 아래 과정을 따릅니다.

```bash
# 필수 라이브러리 설치
pip install PyQt6

# 소스 코드로 바로 실행
python main.py

# PyInstaller를 이용해 단일 실행 파일(.exe)로 빌드
pip install pyinstaller
pyinstaller --noconsole --onefile --name "몽글몽글 메모 스티커" main.py
```
*빌드가 완료되면 `dist/` 폴더 안에 실행 가능한 `.exe` 파일이 생성됩니다.*
